zunda-chinnews

YouTube チャンネル「ずんだもんの世界珍ニュース」の投稿管理ツール

このアプリについて

zunda-chinnews は、YouTube チャンネル ずんだもんの世界珍ニュース の運営者が、自分のチャンネルの動画を管理するためだけに使うツールです。一般には提供していません。

YouTube Data API と YouTube Analytics API を通じて、次のことを行います。

  • 運営者のチャンネルへの動画（ショート・中尺）のアップロードと公開日時の予約
  • 動画のタイトル・説明・サムネイル・字幕・再生リストの設定と更新
  • 運営者のチャンネルの再生数・視聴維持率などの分析データの閲覧

運営者以外の Google アカウントのデータを取得・利用することはありません。

プライバシーポリシー

取り扱う情報と利用目的は プライバシーポリシー に記載しています。

About (English)

zunda-chinnews is a private tool used only by the operator of the YouTube channel "ずんだもんの世界珍ニュース" to upload and schedule videos to that channel, manage their titles, descriptions, thumbnails, captions and playlists, and read the channel's analytics via the YouTube Data API and YouTube Analytics API. It is not offered to the public. See the Privacy Policy.
