プライバシーポリシー

zunda-chinnews（YouTube チャンネル「ずんだもんの世界珍ニュース」の投稿管理ツール）・制定日 2026年10月25日

1. 対象

本ポリシーは、zunda-chinnews（以下「本アプリ」）が Google アカウントの認可を通じて取り扱う情報について定めます。 本アプリは、YouTube チャンネル「ずんだもんの世界珍ニュース」の運営者が自分のチャンネルを管理するためだけに使うもので、一般には提供していません。

2. 取り扱う情報

運営者が本アプリに許可した範囲で、次の情報を取り扱います。

  • 運営者の YouTube チャンネルの情報（チャンネル名・動画・再生リスト・サムネイル・字幕）
  • 運営者の YouTube チャンネルの分析データ（再生数・視聴維持率・登録者の増減など）
  • API を使うための認可情報（アクセストークン・リフレッシュトークン）

運営者以外の Google アカウントやチャンネルの情報は取得しません。

3. 利用目的

  • 運営者のチャンネルへの動画のアップロードと公開日時の予約
  • 動画のタイトル・説明・サムネイル・字幕・再生リストの設定と更新
  • 運営者のチャンネルの分析データの閲覧（投稿の改善のため）

4. 保存と管理

認可情報は運営者のパソコンの中にだけ保存し、外部のサーバーには送りません。取得した情報を第三者に提供・販売することはありません。 広告やそのほかの目的に使うこともありません。

5. Google API サービスのユーザーデータに関するポリシー

本アプリが Google API から受け取った情報の使用および他のアプリへの転送は、 Google API サービスのユーザーデータに関するポリシー （Limited Use の要件を含む）に従います。

本アプリは YouTube API サービスを利用しています。YouTube の利用には YouTube 利用規約 が、Google による情報の取り扱いには Google プライバシーポリシー が適用されます。

6. 許可の取り消し

本アプリへの許可は、いつでも Google アカウントの「サードパーティ製のアプリとサービス」 から取り消せます。取り消すと、本アプリは以後チャンネルにアクセスできません。

7. 変更

本ポリシーを変更するときは、このページを更新します。

Privacy Policy (English summary)

zunda-chinnews is a private tool used only by the operator of the YouTube channel "ずんだもんの世界珍ニュース". With the operator's authorization it accesses that channel's videos, playlists, thumbnails, captions and analytics through the YouTube Data API and YouTube Analytics API, solely to upload and schedule videos, manage their metadata and review the channel's performance. Authorization tokens are stored only on the operator's computer and are never sent to any other server. No data is shared with or sold to third parties, and no data of any other Google account is collected. The app's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Access can be revoked at any time at myaccount.google.com/permissions. This app uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
